# Arrabar split downloads

Extract all four archives into the same folder to combine them. Each archive is independently useful; SVGs embed the original seal and need no external image asset to display.

The recommended cadastral map is `02-cadastral-detailed-v1.8-r02`. Its full PNG is 5700 x 3900. The earlier working cadastral has been omitted from these smaller downloads; it remains in the complete local set and complete ZIP.

These are source reconstructions, not surveyed legal records. Parcel edges, heights and underground geometry are explicitly inferred. Scenic architecture is illustrative. The source scale has not been enlarged to fit the planning population.

Original skill assets, source raster copies and runtime scripts remain on the PC and in the original complete ZIP. They are omitted here to keep each download small. Editable SVGs, geometry data, metadata and review evidence are retained in the relevant parts.

1. `arrabar-editable-01-core-and-geometry.zip`: land-water, detailed cadastral, conceptual relief, five districts, geometry and QA.
2. `arrabar-editable-02-port-netherwaters-atlas.zip`: Port, Netherwaters, atlas, registered isometric SVG.
3. `arrabar-map-pngs-and-previews.zip`: full map PNGs, mobile previews, isometric PNG and contact sheet.
4. `arrabar-scenic-views.zip`: four image-generated scenic views and provenance.
